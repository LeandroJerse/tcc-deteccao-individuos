# Apresentação do TCC

Análise científica de detecção de indivíduos 0 e 2. Aplicação estática HTML/CSS/JavaScript, sem instalação ou servidor de aplicação. Abra index.html ou publique via GitHub Pages.

Inclui sete sistemas, 56 vídeos e 896 imagens de avaliações existentes, filtros, zoom, métricas e fontes. Conteúdo derivado de VISEM-Tracking; preserva limitações da pesquisa. Não contém pesos treinados ou bases completas.

As mídias foram selecionadas por condição congelada; não representam indivíduos únicos. Dados historicamente expostos.
